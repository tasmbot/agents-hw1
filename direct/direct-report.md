# Отчёт о реализации

Создан автономный мини-трекер учебных задач. Чистая логика расчёта
прогресса, фильтрации и валидации находится в `domain.mjs`; `app.mjs`
использует эти функции для обновления интерфейса.

## Фактически выполненные проверки

- `node --test tests/acceptance.test.mjs` — PASS: 5 тестов, 0 ошибок.
  - T1: исходные данные и прогресс 25%.
  - T2: завершение «Практики» и прогресс 75%.
  - T3: фильтрация не меняет общие метрики.
  - T4: валидация пустых, отрицательных, граничных и не кратных 0.5 значений.
  - T5: пустое состояние даёт 0 часов и 0% без `NaN`/`Infinity`.
- `node --check app.mjs` — PASS.
- `node --check domain.mjs` — PASS.

## Исправление UI-дефекта адаптивной вёрстки

При ручном тестировании был обнаружен дефект: на ширине 390px текст
«Прогресс» и процент могли переноситься на разные строки в карточке
статистики. В `styles.css` мобильная карточка изменена на сетку 2+1:
«Всего» и «Готово» занимают первую строку, а «Прогресс» — всю вторую.
Для каждой метрики добавлен запрет переноса внутри строки, поэтому
подпись и значение отображаются вместе.

Автоматически повторно выполнены только тесты доменной логики:
`node --test tests/acceptance.test.mjs`. Требуется повторная ручная
проверка в браузере на ширине 390px: отсутствие горизонтальной прокрутки,
видимость всех трёх метрик и отсутствие переноса/обрезания «Прогресс: N%».
